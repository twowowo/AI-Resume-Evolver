 AI-Resume-Evolver —— 基于 LangGraph 的智能化简历重构与进化全栈平台

 📌 项目简介
本项目是一款专为求职者打造的 AI 智能简历优化与润色平台。系统摒弃了传统的单次 Prompt 渲染模式，创新性地采用 **LangGraph 拓扑工程** 构建了包含“简历解析 -> 痛点诊断 -> 行业对齐 -> 结构化重组 -> 最终审校”的多智能体反思流（Reflection Architecture）。平台支持 PDF 简历一键上传、智能润色及全异步全栈交付。

🛠️ 技术栈
核心图架构：LangGraph /  Python
大模型推理：DeepSeek-V4 / Qwen视觉模型
后端框架：FastAPI 


🚀 核心技术亮点
1. LangGraph 状态机拓扑工程：利用 LangGraph 设计了包含 5 个核心 Node 节点的强约束环状拓扑图。通过大模型反思机制（Self-Correction Loop）在图节点间循环迭代，直至简历质量满足预设阈值，使大模型复杂生成任务的成功率大幅提升。
2. 多模态 XML 隔离防幻觉方案：在 深度推理图节点中，创新引入 ML 标签隔离技术与强制结构化 Pydantic 校验，配合自定义的非法字符动态拦截拦截率达 98% 以上，彻底根治大模型在润色简历时的“虚构简历、词汇拼接、吞标点”等原生幻觉。
3. 高并发异步全栈架构：基于 `FastAPI` 异步事件循环支撑高并发用户访问；通过多图节点间 `State`（状态字典）的精细化设计与多线程池隔离，保障简历高强度解析与润色任务下的响应吞吐。
4. 全链路敏捷部署：支持全套环境的 `Docker` 容器化一键部署与配置隔离，无缝迁移至云服务器，保障系统的敏捷交付与自动化运行。
5. 动态规划与意图路由 Agent 模式：采用 Plan-and-Solve（计划-执行） 架构，由 Router 智能体动态解析用户简历的“技术栈缺陷”与“求职意图”，自适应生成定制化的改写任务队列，并分发至各专项垂直 Agent 执行，实现复杂简历润色任务的动态拆解与精准降维。
